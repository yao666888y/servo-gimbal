# PCA9685 云台接线指南

> 平台：STM32H743ZIT6 + PCA9685 16 路驱动板 + 2 × XTARK 25KG 舵机
> 配套：[CubeMX_PinConfig.md](CubeMX_PinConfig.md)（Phase 1 引脚）· [pinmap.csv](pinmap.csv)
> 接线错误会**直接烧舵机或驱动板**，请按 §5 的顺序上电，不要跳步。

---

## 0. 一句话拓扑

> **信号走驱动板，大电流走电源，所有 GND 汇到一个点。**

```
   STM32 ──(3.3V/GND/SCL/SDA/OE)──> PCA9685 逻辑侧
                                      │
                                      └─(16×3pin)─> 舵机 SIG
   独立 6V 电源 ──(粗线)──> PCA9685 V+ 端子 ──> 舵机 V+/GND
                    └──────── 与 STM32 GND 单点共地 ────────┘
```

---

## 1. 物料清单

| 物料 | 规格 | 数量 | 说明 |
|---|---|---|---|
| 舵机电源 | **6.0–7.4V / ≥10A**（BEC 或 2S 锂电+UBEC） | 1 | 2×25KG 堵转合计可达 10A |
| 电解电容 | 2200µF / 16V 低 ESR | 1 | 并在 V+ 端子，抑制舵机启动跌落 |
| 陶瓷电容 | 0.1µF | 1 | 与电解并联 |
| 保险丝 | 10A 慢熔 + 座 | 1 | 串在电源正极，防短路起火 |
| 电源线 | 16–18AWG（硅胶线） | 若干 | V+ 走线不可用杜邦线 |
| 杜邦线 | 母-母 | 4–5 根 | 逻辑侧 I2C/电源 |
| 上拉电阻 | 2.2k–4.7k | 2 | 板上已有则不加 |

## 2. 电源侧接线（大电流路径，先接这一侧）

```
 6.0–7.4V 电源 +
      │
   [10A 保险丝]
      │
      ├───────────────┬───────────────┐
      │               │               │
   [2200µF]        舵机1 红线      舵机2 红线
      │               │               │
 电源 − ──────────────┴───────────────┴──── PCA9685 GND 端子
                                              │
                                         STM32 GND
```

要点：

1. **V+ 端子用粗线**（16–18AWG），不要用杜邦线过 10A。
2. **电容就近并在 V+ 与 GND 端子上**，极性别反（负极接 GND）。
3. **保险丝串在正极**，10A 慢熔；短路时它先断，而不是板子走线。
4. **单点共地**：电源 −、PCA9685 GND、STM32 GND 只在 PCA9685 的 GND 端子汇合一次，不要形成环路（尤其别让舵机地经 USB 线回到电脑）。

## 3. 逻辑侧接线（STM32 ↔ PCA9685）

| STM32 引脚 | PCA9685 引脚 | 线 | 说明 |
|---|---|---|---|
| 3.3V | VCC | 红 | **逻辑电源，接 3.3V**（见下方说明） |
| GND | GND | 黑 | 必接，且与舵机电源共地 |
| PB10 | SCL | 黄 | I2C2_SCL，AF4 开漏 |
| PB11 | SDA | 绿 | I2C2_SDA，AF4 开漏 |
| PD6 | OE | 蓝 | 低有效；**板上没有 OE 丝印就不接** |
| — | V+ | 粗红 | 独立电源正极（§2） |

**VCC 到底接 3.3V 还是 5V？**

| 接法 | PWM 输出高电平 | I2C 上拉 | 适用 |
|---|---|---|---|
| **VCC = 3.3V（推荐）** | 3.3V | 3.3V | 最安全；XTARK 25KG 认 3.3V 信号 |
| VCC = 5V | 5V | 5V | 舵机要求 5V 逻辑时才用；PB10/PB11 是 FT 脚可承受，但**绝不能与摄像头 SCCB 共总线** |

**上拉电阻**：多数 PCA9685 板自带 10k 上拉（有的可拆）。板上已有就不要再并；板上没有则在 SCL/SDA 各加 **2.2k–4.7k 到 3.3V**。上拉过多会导致 100kHz 波形上升沿变缓。

**OE 说明**：OE 低电平=输出使能。板上若把 OE 直接下拉到 GND（常使能），PD6 不用接；若有 OE 针脚，接 PD6，代码上电先输出 High 关断，初始化完再拉低。

## 4. 舵机接口

PCA9685 上 16 组 3 针排针，**针序各板不同**，必须先看丝印（常见 `G V S` 或 `S V G`）：

| 舵机线色 | 接到 | 说明 |
|---|---|---|
| 棕 / 黑 | **G**（GND） | 地 |
| 红 | **V+** | 舵机电源（来自板上 V+ 母线） |
| 橙 / 黄 / 白 | **S**（SIG/PWM） | 信号，来自 PCA9685 输出 |

通道分配：

| 通道 | 轴 | 代码宏 |
|---|---|---|
| **CH0** | 水平 Pan | `SERVO_CH_PAN = 0` |
| **CH1** | 俯仰 Tilt | `SERVO_CH_TILT = 1` |

> ⚠️ **插反 = 烧**。插舵机前用万用表量排针：G 与 V+ 之间应是 6V 左右（先不接舵机、只上电驱动板），S 与 G 之间静态约 0V。确认后再插。

---

## 5. 上电顺序与验证（严格按序）

**第 1 步：只上逻辑电**
1. 不接舵机、不接 V+。
2. USB 给 STM32 供电，量 PCA9685 VCC = 3.3V。
3. I2C 扫描应看到 `0x40`；读 `MODE1(0x00)` 应为 `0x11`（SLEEP=1，上电默认）。

**第 2 步：只上舵机电源，不插舵机**
4. 接 V+ 与电容，上电，量 V+ 端子 = 6.0–7.4V。
5. 量每组排针 G–V+ 电压 = 电源电压；S–G ≈ 0V（无脉冲）。

**第 3 步：先发中位，再插舵机**
6. 代码里先把 CH0/CH1 写成 **1500µs（off_count=307）**，再拉低 OE。
7. 断电 → 插上舵机 → 上电。此时舵机应**静止在中位**，不应"啪"一下打到极限。

**第 4 步：示波器确认**
8. 探头接 S 与 G：**1.5ms 高 / 19.99ms 周期**（50.03Hz）。
9. 扫 1000→2000µs，看舵机平滑跟随、无异响、无抖动。

**第 5 步：负载测试**
10. 带云台机械负载运行 10 分钟，摸舵机与 V+ 端子温度、看电压跌落（示波器 AC 耦合看纹波，应 < 300mV）。

## 5.5 V+ 电压监测（固件已支持，建议接）

从 V+ 分压到 PC0（ADC1_INP10），固件每 100ms 采样一次，状态帧里带回电压：

```
V+ (6~8.4V) ──[ 10k ]──┬── PC0
                        │
                    [ 3.3k ]
                        │
                       GND
```

| 项 | 值 |
|---|---|
| 分压比 | 3.3 / (10 + 3.3) = 0.248 |
| 7.4V 时引脚电压 | 1.84V |
| 量程上限 | 13.3V（超过会饱和） |
| 电阻精度 | 建议 1%，否则读数有 2–3% 偏差 |

读数在哪里：`0x84` 状态帧最后两个字节（小端，单位 mV）。舵机动作时电压会掉 100–300mV，可以据此判断"舵机到底有没有在吃电流"。

## 6. 常见坑（按踩坑概率排序）

| # | 坑 | 后果 | 规避 |
|---|---|---|---|
| 1 | 舵机插反（V+ 与 G 对调） | **瞬间烧舵机/板** | 插前万用表量针序 |
| 2 | 忘记共地 | I2C 不通或随机丢包 | 单点共地，量 GND 间电阻 ≈ 0Ω |
| 3 | 用开发板 5V 给舵机供电 | 掉压复位、烧稳压器 | 独立电源，本项目硬性规定 |
| 4 | 大电流走杜邦线 | 线发热、压降大、舵机抖动 | V+ 用 16–18AWG |
| 5 | 无电容 | 启动瞬间电压跌落导致 MCU 复位 | 2200µF 就近并在端子上 |
| 6 | VCC 接 5V 又与摄像头共用 I2C | 5V 上拉打坏 OV5640 | 本项目已分两条总线 |
| 7 | OE 悬空 | 输出状态不确定 | 接 PD6 或板上下拉 |
| 8 | 上电即输出 0.5ms | 云台猛地打到极限、撞限位 | 先写 1500µs 再使能 |
| 9 | 电源与 USB 同时供电形成地环 | 通信偶发错误 | 单点接地，必要时 USB 加磁环 |

## 7. 与代码的对应关系

| 接线 | 代码位置 |
|---|---|
| PB10/PB11 → I2C2 | `hi2c2`，地址 `0x40 << 1` |
| PD6 → OE | `HAL_GPIO_WritePin(SERVO_OE_GPIO_Port, SERVO_OE_Pin, GPIO_PIN_RESET)` 使能 |
| V+ 电压 | 可选 `PC0/ADC1_INP10` 分压监测（12V 经 10k/3.3k 分压） |
| CH0/CH1 | `BSP_Servo_SetPulseUs(SERVO_CH_PAN, 1500)` |

初始化顺序（代码必须照此写）：

```
1. 拉高 OE（输出关断）
2. 写 PRESCALE = 121（必须先 SLEEP=1 才能写）
3. 清 SLEEP，等 500µs，发 RESTART
4. 写 MODE2 = 0x04（推挽输出）
5. CH0/CH1 写 1500µs
6. 拉低 OE（输出使能）
```
